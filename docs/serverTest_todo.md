## 危险派对多人模式测试

验证击鼓传花（`tothesky:hot_potato`）多场并发 + 全流程：

- [ ] 喝下危险派对 → 获得「击鼓传花」效果（橙色图标，名称显示正确），广播开场消息。
- [ ] 每 10 秒收到全服广播「xxx身上的击鼓传花还剩余xx秒」。
- [ ] 攻击别人 → 效果传给对方（对方获得效果 + 短暂失明/迟缓），广播传递消息，攻击者效果消失。
- [ ] 60 秒未传出 → 持有者被击杀 + 广播「没能及时把好运传给下一个人」。
- [ ] **多人同时喝** → 应见多场独立进行（各带各的时钟），互不覆盖、互不报错。
- [ ] 喝其它鸡尾酒（david / call_of_tahiti / free_nightingale / silent_midnight / shoal_in_dream / lago_de_texcoco）确认 buff / 自定义效果正常、不崩溃。
- [ ] 创造栏「胡萝卜厨房-鸡尾酒」标签能看到全部 7 种 fstwines 鸡尾酒。

排查提示：若某场异常，看 `run/logs/latest.log` 是否有 `hot_potato` / `DelayedTasks` 相关的 exception。

## 售货机 / 扭蛋机测试

验证售货机（`tothesky:seller`）与扭蛋机（`tothesky:roller`）的放置、交互、容器保护、防刷防吞：

### 基础功能
- [ ] **放置朝向**：售货机/扭蛋机放置后朝向玩家（四朝向 N/E/S/W 均正确）。
- [ ] **放置记录 owner**：放置者右键查看时显示自己的售货机，其他人右键显示"属于 xxx"。

### 售货机交互
- [ ] **店主右键加价**：右键+1，潜行右键+0.1，actionbar 显示"当前价格：x.xΔ"。
- [ ] **店主左键减价**：左键-1，潜行左键-0.1，价格不低于 0。
- [ ] **顾客右键查看**：显示"这个售货机属于 xxx，每个 <商品名> x.xΔ"。
- [ ] **顾客左键购买**：消耗物品栏中的三角币(10Δ)/三角片(1Δ)，获得 1 件商品，找零退回。
- [ ] **余额不足**：余额低于价格时提示"你的现金余额少于此商品的价格！"，不扣款不吞物品。
- [ ] **商品为空**：上方容器无货时提示"售货机已空！"。

### 扭蛋机交互
- [ ] **店主持抽奖券右键绑定**：券获得附魔光效 + NBT key，提示"抽奖券已绑定！"——**不消耗券**。
- [ ] **已绑定的券不可覆盖**：再次绑定提示"无法覆盖已绑定的抽奖券"。
- [ ] **无下方容器 + 手持匹配券右键**：消耗 1 张券，随机获得上方容器中的 1 件物品。
- [ ] **无下方容器 + 手持不匹配券**：提示"抽奖券与扭蛋机不匹配"，不消耗不抽取。
- [ ] **有下方容器 + 右键**：从上方随机取 1 件放入下方容器（机械接入模式，无需券）。
- [ ] **上方容器为空**：提示"扭蛋机已空！"。

### 容器保护
- [ ] **非拥有者不可破坏机器**：左键破坏提示"你无法破坏：此售货机/扭蛋机属于 xxx！"，方块不消失。
- [ ] **拥有者破坏且上方容器非空**：提示"请先清空上方容器再破坏售货机/扭蛋机！"。
- [ ] **拥有者破坏且上方容器已空**：可正常破坏。
- [ ] **非拥有者右键上方容器**：提示"你无法打开：此容器属于 xxx！"，不打开菜单。
- [ ] **拥有者右键上方容器**：正常打开。

### 防刷防吞
- [ ] **物品栏满时购买**：商品溢出丢地上（不吞）。
- [ ] **物品栏满时找零**：三角币/三角片溢出丢地上（不吞）。
- [ ] **有下方容器时扭蛋输出**：下方容器满时溢出丢地上（不吞）。
- [ ] **连续快速左键购买**：不会刷出多于余额的物品。

### 不同模组容器兼容性
- [ ] 上方放原版箱子 → 正常读写商品/奖品。
- [ ] 上方放 Create 漏斗/黄铜漏斗 → 正常读写。
- [ ] 上方放 Storage Drawers 抽屉 → 正常读写（IItemHandler 兼容）。
- [ ] 下方放其它模组容器（如木桶）→ 扭蛋机正常输出。

排查提示：若交互异常，看 `run/logs/latest.log` 是否有 `Capability` / `IItemHandler` / `seller` / `roller` 相关的 exception；容器兼容性问题通常是该模组未正确注册 `Capabilities.ItemHandler.BLOCK`。
