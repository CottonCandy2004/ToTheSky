# 星露谷式日历系统实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 可放置日历方块 + 只读翻月 GUI + REST CRUD API + SavedData 持久化。

**Architecture:** `CalendarBlock.use()` 服务端取 CalendarData → CalendarDataPacket 打开客户端屏幕；REST（JDK HttpServer）经 `server.execute()` 改 CalendarData 后广播同包刷新；数据存 Overworld SavedData。

**Tech Stack:** Forge 1.20.1（47.4.10）、Java 17、SimpleChannel、com.sun.net.httpserver、Gson。
