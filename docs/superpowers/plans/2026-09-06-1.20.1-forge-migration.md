# ToTheSky 1.20.1 Forge 迁移实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 `1.20.1` 分支把模组从 NeoForge 1.21.1 迁移到 Forge 1.20.1（Forge 47.4.0，参考实例 `D:\Minecraft\Client\.minecraft\versions\RIAFst 3` 的实际版本），`gradlew build` 编译通过。

**Architecture:** 构建脚本从 `net.neoforged.moddev` 换成 ForgeGradle 6（`net.minecraftforge.gradle`）+ 官方/ parchment 映射。代码层：注册表改 `DeferredRegister.create(ForgeRegistries.X, MODID)` + `RegistryObject`；数据组件改 NBT；附件改 Forge persistentData；方块交互 `use()/attack()` 合并签名；kk 鸡尾酒从注册表驱动降级为 NBT+数据驱动（三个类删除）。资源：`recipe/`→`recipes/`、result `id`→`item`、`c:` tag→`forge:` tag、流体 ingredient 去 `neoforge:single` 包装。

**Tech Stack:** Minecraft 1.20.1, Forge 47.4.0, ForgeGradle 6.0.x, Java 17 (编译目标), Parchment 1.20.1, 依赖：Create 0.5.1.j、FarmersDelight 1.2.4、kitchenkarrot 1.20.1-0.6.4b（本地文件依赖，来自参考实例 mods 目录）。

## 风险与保底

- **不确定 API（编译时逐一确认）**：FLUID_TYPES 注册方式、RegisterClientExtensionsEvent 的 fluidType 方法、ServerTickEvent server 引用、`CustomUseEffectsItem` Boolean 返回、MobEffects 返回类型、Item.initializeClient。全部有保底方案（见各任务），不阻塞环境搭建。
- **本地 jar 依赖**：libs/ 不进 git（.gitignore），开发者从参考实例复制。另在 README 或 AGENTS.md 记录来源路径。
- **kaleidoscope_cookery 等其余依赖**：1.20.1 有对应版本（参考实例 jar 在），但仅 Create/FD/kk 参与 Java 编译面；其余只作为数据配方引用（运行时才需），先不进编译类路径。
- **`forge:` tag**：1.20.1 时代 c: 与 forge: 并存——原 kjs 脚本 1.20.1 时用的就是 `forge:`（kjs data 目录佐证），配方改 `forge:`。
- **回滚**：main 分支不受影响；1.20.1 分支独立提交链。
